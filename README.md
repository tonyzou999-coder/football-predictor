# 神谕足球预测 🔮

基于 ESPN 公开赛程数据的足球比赛预测工具，**无需任何 API Key**。

## 功能

- 📅 实时抓取 ESPN 全球足球赛程（今天/昨天/明天）
- 🏆 按联赛筛选比赛
- 🔮 4种预测模型：泊松进球率、ELO评级、状态分析、全模型综合
- ⚡ 10分钟本地缓存，避免频繁请求

## 使用方法

```bash
node server.js
```

然后打开浏览器访问 http://127.0.0.1:8768

## 技术栈

- 纯 Node.js（无需安装任何依赖）
- 原生 HTML/CSS/JS 前端
- ESPN 公开 API 数据源
